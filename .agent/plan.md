## Project Brief

# Project Brief: SNDP MS Nattika

This brief outlines the Minimum Viable Product (MVP) for the **SNDP MS Nattika** Android application, designed for the Sree Narayana Dharma Paripalana Sangham Maranaananthara Samithi Nattika.

## Features

1.  **Secure Authentication & Onboarding**: A unified login system for Admins and Members using mobile numbers. It includes a mandatory password change on the first login to ensure account security.
2.  **OTP-Based Password Recovery**: A self-service mechanism for users to reset their passwords via One-Time Password (OTP) verification after they have moved past the default setup.
3.  **Adaptive Role Dashboards**: Distinct Home Pages for Admins and Members that utilize responsive design to provide an optimized experience across various screen sizes (phones, tablets, etc.).
4.  **Admin Member Management**: A specialized module for administrators to create and manage login credentials for organization members.
5.  **Branded Splash Screen**: A professional entry screen that handles background initialization and smooth transition to the authentication flow.

## High-Level Technical Stack

*   **Kotlin**: The primary language for robust and concise Android development.
*   **Jetpack Compose**: The modern toolkit for building declarative and reactive user interfaces.
*   **Jetpack Navigation 3**: A state-driven navigation architecture to handle complex flows between login, member views, and admin panels.
*   **Compose Material Adaptive**: Used to implement flexible layouts that automatically adjust to different device form factors.
*   **Kotlin Coroutines**: For efficient handling of asynchronous operations such as authentication requests and state loading.
